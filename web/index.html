Team को app में कैसे लाएँ

  1. ऊपर Member जोड़ें. उसी समय उनका Login ID और password बनेगा. Password सिर्फ एक बार दिखेगा — उसे WhatsApp पर भेज दें.
  2. उन्हें Team Kaam का APK या app link भेजें. App खोलकर वो अपना ID और password डालेंगे.
  3. किसी का password भूल जाए तो उनके नाम के आगे “नया Password” दबाएँ. पुराना password तुरंत बंद हो जाएगा.
